## Confirmed usability gaps / next priorities

1. **Refresh interrupts web sessions and quizzes.** Web credentials are intentionally memory-only. Reload signs out and returns to welcome; after signing in and reopening the saved quiz, it starts at question 1 with no unsubmitted choices selected. Generated quizzes, submitted attempts and other saved server artifacts remain intact. Do not silently solve this by storing bearer tokens in localStorage; choose a proper web session design and an explicit account-scoped quiz-draft strategy if web becomes a supported product target.
2. **PDF text needs zoom.** Original landscape lecture slides fit a narrow viewport but the text is small, and the app offers page controls/extracted text rather than a dedicated zoom control. The accessible text mode helps, but original-source inspection needs a better zoom/pan experience.
3. **History needs clearer resource context.** Rows use technical states such as “succeeded” and generic summary/quiz titles. Show student-facing state labels and the document/course title to distinguish saved sessions.

These are product usability gaps, not findings that current generated artifacts or grades are lost from the server. The visual identity is coherent; the next work should improve continuity/readability and preserve the approved identity.
